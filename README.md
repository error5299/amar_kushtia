## 📖 পরিচিতি (Overview)

**আমার কুষ্টিয়া (Amar Kushtia)** হলো কুষ্টিয়া জেলার গণমানুষের জন্য তৈরি একটি নির্ভরযোগ্য, আধুনিক এবং দ্রুতগতির জেলা ডিজিটাল সহকারী মোবাইল অ্যাপ্লিকেশন। কুষ্টিয়া সদর, কুমারখালী, খোকসা, ভেড়ামারা, মিরপুর এবং দৌলতপুর—এই ৬টি উপজেলার নাগরিক ও দর্শনার্থীরা এক ক্লিকেই সমস্ত জরুরি যোগাযোগ, সেবা ও তথ্য সরাসরি তাদের স্মার্টফোনে পেয়ে যাবেন।

## ✨ প্রধান ফিচারসমূহ (Key Features)

### 🚨 জরুরি সেবা ও হটলাইন (Emergency Services)
- **২৪/৭ হেল্পলাইন:** জাতীয় জরুরি সেবা ৯৯৯, ফায়ার সার্ভিস ১০২, সরকারি তথ্য সেবা ৩৩৩ ও নারী নির্যাতন প্রতিরোধ ১০৯।
- **থানা ও পুলিশ ফাঁড়ি:** কুষ্টিয়া মডেল থানা, হাইওয়ে পুলিশ ও প্রতিটি উপজেলার ওসির সরাসরি ফোন নম্বর।
- **অ্যাম্বুলেন্স ও ব্লাড ব্যাংক:** কুষ্টিয়ার সক্রিয় রক্তদাতা সংগঠন ও তাৎক্ষণিক অ্যাম্বুলেন্স সেবা।

### 🚌 পরিবহন ও ভ্রমণ গাইড (Travel & Transit)
- **বাস কাউন্টার ডিরেক্টরি:** গোল্ডেন লাইন, শ্যামলী, এসবি, হানিফসহ মজমপুর, চৌড়হাস, কুমারখালী, খোকসা ও ভেড়ামারা কাউন্টারের হালনাগাদ মোবাইল নম্বর।
- **লোকাল বাস ভাড়া ক্যালকুলেটর:** উপজেলার যেকোনো স্থান থেকে অন্য স্থানের সরকারি বাস ভাড়ার তালিকা।
- **ট্রেন সময়সূচি:** কুষ্টিয়া কোর্ট, পোড়াদহ জংশন ও ভেড়ামারা স্টেশনের আন্তঃনগর ও মেইল ট্রেনের শিডিউল (টাইম টেবিল-৫৪)।

### 🏥 স্বাস্থ্যসেবা ও হাসপাতাল (Healthcare Directory)
- কুষ্টিয়া ২৫০ শয্যা জেনারেল হাসপাতাল ও সকল উপজেলা স্বাস্থ্য কমপ্লেক্স।
- বিশেষজ্ঞদের চেম্বার, হাসপাতালের ওয়ার্ড ফি ও নিয়মিত সার্জারি শিডিউল।

### 🏛️ দর্শনীয় স্থান ও ঐতিহ্য (Tourism & Heritage)
- বাউল সম্রাট ফকির লালন শাহের মাজার
- রবীন্দ্রনাথ ঠাকুরের শিলাইদহ কুটিবাড়ি
- মীর মশাররফ হোসেন স্মৃতি কমপ্লেক্স
- ঐতিহাসিক হার্ডিঞ্জ ব্রিজ ও লালন শাহ সেতু

### ⚙️ স্বয়ংক্রিয় অ্যাপ আপডেট ও রিলিজ ম্যানেজমেন্ট (Live App Updates)
- **ইন-অ্যাপ আপডেট নোটিশ:** অ্যাপ চালু করার সাথে সাথে নতুন রিলিজ থাকলে পপআপ নোটিফিকেশন।
- **ডিরেক্ট ডাউনলোড ও ইনস্টল:** অ্যাপের ভেতর থেকেই রিয়েল-টাইম প্রগ্রেস বার সহ নতুন APK ডাউনলোড ও ইনস্টল করার সুবিধা।
- **অ্যাডমিন পোর্টাল CMS:** ওয়েব অ্যাডমিন থেকে তাৎক্ষণিকভাবে নতুন ভার্সন, বিল্ড নম্বর ও চেঞ্জলগ প্রকাশ করার ক্ষমতা।

## 🚀 লোকাল সেটআপ ও রান করার নিয়ম (Getting Started)

### ১. রিপোজিটরি ক্লোন করুন
```bash
git clone https://github.com/belayet/amar_kushtia.git
cd amar_kushtia
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন
```bash
flutter pub get
```

### ৩. কোড অ্যানালাইসিস ও টেস্ট
```bash
flutter analyze
flutter test
```

### ৪. অ্যাপ রান করুন
```bash
# ডিবাগ মোডে চালু করতে
flutter run

# প্রোডাকশন রিলিজ APK বিল্ড করতে
flutter build apk --release
```

## 📦 গিটহাব রিলিজ তৈরির নিয়ম (How to Create a Release)

এই রিপোজিটরিতে **GitHub Actions** ওয়ার্কফ্লো যুক্ত রয়েছে। নতুন কোনো ভার্সন প্রকাশের জন্য শুধুমাত্র একটি গিট ট্যাগ পুশ করলেই স্বয়ংক্রিয়ভাবে রিলিজ তৈরি হয়ে যাবে:

```bash
# উদাহরণস্বরূপ বেটা ১.০ রিলিজের জন্য ট্যাগ পুশ করুন:
git tag v1.0.0-beta.1
git push origin v1.0.0-beta.1
```
অ্যাকশনস স্বয়ংক্রিয়ভাবে:
1. কোড টেস্ট ও অ্যানালাইজ করবে
2. `app-release.apk` বিল্ড করবে
3. গিটহাবের **Releases** সেকশনে সরাসরি APK ফাইল আপলোড করে রিলিজ প্রকাশ করবে!
